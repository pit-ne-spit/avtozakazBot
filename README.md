# Avtozakaz74 Bot 🚗

Telegram бот для автоматизации приема заявок на подбор автомобилей из Китая.

## 🎯 Возможности

- 📢 Прием заявок из Telegram канала
- 🌐 Прием заявок с веб-сайта
- 💬 Интерактивный диалог с пользователем
- ⌨️ Inline клавиатура с кнопками в сообщениях
- 📊 Сбор информации: бюджет, предпочтения, сроки
- 🔔 Автоатические уведомления нескольким менеджерам
- 📝 Сохранение всех лидов в базе данных
- 🔗 Отслеживание источника лида (канал/сайт)

## 📋 Требования

- Python 3.10+
- Telegram Bot Token (от @BotFather)
- ID администраторов/менеджеров

## 🚀 Установка

### 1. Клонирование репозитория

```powershell
cd C:\Users\parap\PycharmProjects\avtozakazBot
```

### 2. Установка зависимостей

```powershell
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Создайте файл `.env` на основе `.env.example`:

```powershell
Copy-Item .env.example .env
```

Отредактируйте `.env` и укажите:

- `BOT_TOKEN` - токен вашего бота от @BotFather
- `ADMIN_IDS` - ID менеджеров через запятую (получить у @userinfobot)

Пример `.env`:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_IDS=123456789,987654321
DATABASE_URL=sqlite+aiosqlite:///bot.db
```

### 4. Запуск бота

```powershell
python main.py
```

## 📱 Создание бота в Telegram

1. Откройте @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Укажите имя бота (например: `Avtozakaz74 Bot`)
4. Укажите username (например: `avtozakaz74_bot`)
5. Скопируйте полученный токен в `.env`

## 💬 Команды бота

- `/start` - Начать диалог
- `/help` - Справка
- `/cancel` - Отменить текущий диалог

## ⌨️ Inline клавиатура

Бот использует Inline кнопки, которые отображаются прямо под сообщениями:

**Основные кнопки:**
- 🚗 **Начать заново** / ▶️ **Старт** - начать диалог
- ❌ **Отменить** - отменить текущий диалог
- 📞 **Контакты** - показать контакты компании
- ℹ️ **Справка** - показать справку по боту
- 🌐 **Подобрать авто на сайте** - переход на https://avtozakaz74.ru/

## 🗄️ База данных

Бот использует SQLite (можно переключить на PostgreSQL).

**Таблицы:**
- `users` - информация о пользователях
- `conversations` - активные диалоги
- `leads` - завершенные заявки
